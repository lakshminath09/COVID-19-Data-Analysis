# COVID-19 Data Analysis

## 📌 Project Overview

**COVID-19 Data Analysis** is a Data Science project that focuses on cleaning, exploring, and visualizing COVID-19 data using Python. The project demonstrates how data analysis techniques can be used to understand pandemic-related information and identify meaningful patterns and trends in the dataset.

## 🎯 Objectives

- To load and understand the COVID-19 dataset.
- To identify and handle missing or inconsistent data.
- To perform Exploratory Data Analysis (EDA).
- To analyze COVID-19-related patterns and trends.
- To create visualizations for better data interpretation.
- To develop practical data analysis skills using Python libraries.

## 📂 Dataset

The project uses the `covid_19_clean_complete.csv` dataset, which contains COVID-19-related records across different countries and dates.

The dataset is used to explore the available attributes, examine data quality, and visualize trends based on the information provided.

## 🛠️ Technologies Used

- **Python** – Programming language for data analysis.
- **Pandas** – Data cleaning, manipulation, and analysis.
- **Matplotlib** – Creating graphs and visualizations.
- **Jupyter Notebook** – Writing and executing analysis code.

## 🔄 Project Workflow

1. **Data Loading:** Import the dataset into Python using Pandas.
2. **Data Inspection:** Examine the dataset structure, columns, and data types.
3. **Data Cleaning:** Check for missing values and prepare the data for analysis.
4. **Exploratory Data Analysis:** Explore the dataset to understand its characteristics and patterns.
5. **Data Visualization:** Create graphical representations to make the findings easier to understand.
6. **Interpretation:** Examine the results and summarize the observations from the analysis.

## 📊 Key Features

- COVID-19 dataset exploration.
- Data cleaning and preprocessing.
- Exploratory data analysis.
- Graphical representation of data.
- Identification of patterns and trends in the available data.

## ▶️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/lakshminath09/COVID-19-Data-Analysis.git
   ```

2. Navigate to the project directory:

   ```bash
   cd COVID-19-Data-Analysis
   ```

3. Install the required libraries:

   ```bash
   pip install pandas matplotlib jupyter
   ```

4. Make sure the `covid_19_clean_complete.csv` dataset is available at the file path specified in the notebook.

5. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Open `COVID-19-Data-Analysis.ipynb` and execute the cells in order.
